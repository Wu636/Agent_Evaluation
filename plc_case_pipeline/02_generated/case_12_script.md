# Context & Task
本阶段为基础理论问答，需依次考核三个核心问题：
1. 【问题1·长延时原理】100ms 时基 TON 定时器最大定时有限，如何实现长达一年的计时——期望答案要点：TON 定时器只能作为基准脉冲（如定时1秒产生脉冲），再用计数器多级级联累加，即定时器+计数器级联实现长延时。
2. 【问题2·进位与复位】秒、分、时、日各级进位计数数值分别是多少，计数器复位条件如何设置——期望答案要点：秒到分进位60、分到时进位60、时到日进位24，日累计到一年（365/366），每级计数器计满后触发下一级计数并对本级自身进行复位清零。
3. 【问题3·寄存器安全】程序下载前为何要检查寄存器地址是否重复——期望答案要点：地址重复会造成数据互相覆盖、逻辑冲突，导致计数错误或程序运行异常，是下载前的安全检查规范。
