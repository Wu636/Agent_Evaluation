# 《导管的代价》：离线规划、分段生成与注入方案

已将这份教师文档做成配置审核稿，并制作可复用的 `training-config-injector` 技能。生成阶段由 agent 当前模型完成，配置和检查点保存在文件中；注入阶段优先复用当前系统的注入接口，由系统按节点写入平台。无需先等待网页“智能规划”成功。

## 当前超时链路的发现

两份附件完全一致，单份正文为 5,157 字符。当前项目的规划入口 `frontend/app/api/training-generate/plan/route.ts` 声明 `maxDuration = 180`，等到整份规划完成后才返回 JSON。`generator.ts` 的 `requestTrainingPlan` 没有独立请求截止信号；主规划后还可能串行做格式修复、字段补全、模块定向补全。这些环节会累积等待时间。

当前实现只有超过 12,000 字符才优先采用压缩文档；本案首轮走原文，规划输出上限为 2,200 tokens。输出字段多时还存在截断后进入修复链路的风险。以上是代码层面的风险定位；本次没有取得该失败请求的服务日志，具体超时来自模型服务、网关还是托管时限仍待日志确认。

## 方案为什么更稳

1. 完整摄取来源并建立索引，不以删除小结、逐字稿或尾部要求换取缩短输入。
2. 先列出教学约束和流转骨架，再逐阶段生成；每段完成就存文件，失败只重做对应段。
3. 用确定性脚本拼装 Markdown、检查图连通性、原文覆盖和分值，不再让模型重新提取已经结构化的配置。
4. 当前系统通过既有注入接口按节点创建、补齐内容、连线并写入评分；按SSE事件保存进度，中断后先回采目标再决定补齐方式。只有环境中没有系统且用户接受时，才采用具有逐请求检查点的直连备用工具。
5. 配置写入后再读取，逐项比较提示词、开场白、轮次、跳转及评分，避免只看到“请求成功”就报告完成。

技能不会消除模型上下文上限、网络错误或平台限制；它将一次长事务拆成能恢复的小任务。若将来改网页，建议采用“创建后台任务→返回任务编号→查询进度”，并按来源、规划、节点、评分、校验、注入分别保存状态。流式进度改善等待体验，仍须由后台任务和检查点解决整体执行时间问题。

## 本案的具体规划

保留原文五个教学阶段，其中专业训练为阶段二至五。平台分成 12 张卡片：

| 顺序 | 环节 | 作用 |
| --- | --- | --- |
| 1 | 阶段一：案例摘要与角色锁定 | 展示课程对标、原文案情并选择岗位 |
| 2 | 阶段二：第一轮线索与任务 | 公共必答＋所选岗位必答＋自主选做 |
| 3 | 阶段二：原理性小结 | 逐字显示教师原文，再进入阶段三 |
| 4 | 阶段三：第二轮线索与任务 | 增加第一道统一反向质疑 |
| 5 | 阶段三：原理性小结 | 逐字显示教师原文，再进入阶段四 |
| 6 | 阶段四：第三轮线索与任务 | 增加第二道统一反向质疑 |
| 7 | 阶段四：原理性小结 | 逐字显示教师原文，再进入阶段五 |
| 8 | 阶段五：治疗决策 | 完成处置与院感管控任务 |
| 9 | 阶段五：小结与作答结束确认 | 收束任务，确认后展示结束后的学习材料 |
| 10 | 四角色拓展问题全景 | 展示四岗位×四阶段的全部 16 道原文问题 |
| 11 | 通用易错点自查 | 逐字展示教师三处易错点，请学生自己核对 |
| 12 | 个人复盘与六维画像 | 按实际作答给分、指出薄弱点并提出练习建议 |

教师原文有阶段二、三、四三份逐字小结，均原样保留。原文没有独立的阶段一和阶段五小结：阶段一以角色锁定收束，阶段五增加据原任务提炼的收束提示，明确这是生成内容。

公共任务决定线索门控；角色题必须实质作答，质量不足在角色维度扣分；主动探究自主选做，放弃只损失对应分数。维度分值保持 22、22、24、12、10、10，总分 100；主动探究全部放弃时最高 90。细分得分点和未给出的公共合格证据清单属于生成建议，已标注。

## 文件与使用

- `dist/智能规划.json`：符合当前项目规划数据类型的离线规划；当前页面尚无为此新增导入入口，可供 agent 继续处理。
- `dist/训练剧本配置.md`：可供现有 Markdown 注入流程解析的完整配置审核稿。
- `dist/评价标准.md`：六维评分和细目。
- `manifest.json`、`stages/`、`rubric.json`：分段修改及续跑的源配置。
- `validation.json`：30 项来源与落点覆盖检查。
- `教师内容核对.md`、`review-issues.json`：需要教师核对的原文内容。
- `验收报告.md`：实际完成的测试及学生端待验收项。

技能已放置在本机 `~/.codex/skills/training-config-injector`，同时提供带根目录的 ZIP，方便交给其他支持本地文件和脚本执行的 agent。运行脚本仅依赖 Python 3.10+ 标准库；生成由 agent 完成，不需额外配置另一套模型 API。

可直接向 agent 提出：

> 使用 $training-config-injector，根据教师文档和补充要求分阶段生成实训配置；保留原文阶段小结、四角色问题全景、易错点自查和个人复盘。完成来源覆盖校验后，向我指定的空能力训练任务注入，并回采核对。中断时沿用工作目录续跑。

已向用户指定的目标训练写入教师编辑稿并回采核对；本案仍有 4 项内容核对条目。平台的跨节点历史、条件跳转、原文开场白显示及最大轮次自动推进行为需要在实际学生端验收，提示词和高轮次配置本身不构成硬门控保证。
