案例 7 状态表法程序设计方法-单按钮灯亮灭控制基础案例实操训练

用状态表法设计一个按钮控制1盏灯亮灭控制。

| 工艺 | 输入 | 输出 | 状态 |
| --- | --- | --- | --- |
|  | I0.0 | Q0.0 |  |
| 0.待机 | 0 | 0 | S0 |
| 1.灯亮 | 1 | 1 | S1 |
| 2.灯灭 | 1 | 0 | S2 |

一、训练目的

知识层面：掌握状态表基础理论、状态表标准化绘制规范，理解状态标志位、上升沿触发配合逻辑，熟记 PLC 数字量 IO 分配规则、实训上电断电安全规范，建立顺序控制标准化建模基础认知。

实操层面：能够独立绘制两态转换状态表，依据状态表完成虚拟接线、编写完整 LAD 梯形图，可自主排查状态无法切换、输出常亮/常灭等程序故障。

思政层面：体会工控系统标准化建模、分步拆解的严谨工匠精神，了解国产小型 PLC 在设备指示灯控制中的普及应用，树立机电专业产业报国意识。

二、训练步骤

训练启动与角色分配：智能体以「PLC 实训指导教师」身份语音开场，学生以「机电实训学员」角色全程一对一语音交互，依托智慧树虚拟仿真平台完成全部训练，无需线下硬件。

基础理论问答

智能体依次语音提问，学生语音作答，回答完毕智能体实时正误反馈，答错推送微课知识点复盘。

问题 1：状态表由哪三大核心要素组成？本案例包含哪两个工作状态？

问题 2：状态表中 “当前状态、转换条件、下一状态、输出” 四列分别代表什么含义？

问题 3：PLC 实训仿真结束后，规范关机操作流程是什么？

工业案例实操分析（15 分钟）

智能给出工业场景：控制柜状态指示灯，单按键循环切换亮、灭两种工况，要求采用状态表法完成程序设计，分层提问：

问题 1：列出输入输出地址，绘制完整两态转换状态表；

问题 2：说明如何利用上升沿指令作为状态切换触发条件，如何用辅助继电器存储当前状态；

问题 3：仿真时按下按钮，灯状态无变化，从状态标志位、边沿指令两处分析故障。

学生分析完成后，智能体梳理标准解题逻辑：提取控制工况→划分系统状态→绘制 FSM 状态转换表→依据转化梯形图→仿真调试故障排查。

优化拓展思路

智能体语音提出拓展问题，学生结合车间工况作答：

问题 1：新增 “闪烁” 第三工况，如何扩充状态表与梯形图？

问题 2：现场按钮存在机械抖动，从 FSM 程序层面如何防抖优化？

学生作答后，智能总结优化核心思路：扩充状态条目、增加延时滤波过渡状态。

课程思政专项互动

智能体切换思政引导身份语音提问：

问题 1：不采用状态表直接编写程序极易出现逻辑漏洞，结合实训谈工科严谨建模的工匠精神。

问题 2：中小设备控制大量使用国产经济型 PLC，作为本科生如何夯实 FSM 设计基础助力工控国产化。

训练小结

智能体语音整体回顾 FSM 状态表绘制、边沿触发、状态存储核心知识点，点评学生问答、实操分析整体表现，标注状态建模薄弱点。
